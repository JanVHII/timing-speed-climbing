# timing-speed-climbing
Zeitmessung für Speedklettern auf mit arduino und mpr121 break-out

## Teileliste
- Arduino Nano
- 2x Kapazitiver Berührungssensor MPR121 
- 2x Kupferplatte (Frühstartpad Fuß und Anschlag oben)
- 2-zeiliges Display LCD1602-I2C
- I2C Verstärker für lange Kabelverbindungen LTC4311 I2C Extender
- Buzzer für Tonfolge Startsignal
- evtl. 2x Taster für Reset und manuellen Start-Stop
- Kabel und Verbinder
